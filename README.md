# FE 500問道場

IPA「基本情報技術者試験 シラバス Ver.9.2 (2026)」を学習用に再構成した、静的Web問題集です。

## 使い方

`index.html` を開くだけでも動作します。GitHub Pages に載せる場合は、このリポジトリをGitHubへpushして **Settings → Pages → Deploy from a branch → main / root** を選択してください。

## ファイル

- `index.html` UI
- `style.css` デザイン
- `app.js` 出題・採点・localStorage
- `questions.js` 500問の問題データ

## 機能

- 全500問
- テクノロジ系 / マネジメント系 / ストラテジ系フィルタ
- 順番 / ランダム / 間違えた問題だけ復習
- 正答率と復習候補の表示
- 学習履歴をブラウザに保存
- 各問に関連用語を表示

## 出典・注意

問題の分類・学習範囲・用語は、IPA「基本情報技術者試験 シラバス Ver.9.2 (2026)」を基礎資料として再構成しています。問題文と解説文は学習用に新規作成したもので、IPA公式の過去問題そのものではありません。
